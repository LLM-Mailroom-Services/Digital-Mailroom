[`Lucius-Morningstar/mailroom-dataset`](https://huggingface.co/datasets/Lucius-Morningstar/mailroom-dataset) is the corpus every Mailroom repository measures against. The Hub calls this dataset **v1**. The corpus family's lineage calls it **v9**. Both names refer to the same 3,302 documents.

## What it is for

`mailroom-dataset` is an **evaluation and ingress-simulation corpus**. It simulates documents arriving at the mailroom so classification, routing, extraction, grouping, adjudication, and recovery can be measured end to end. It is **not** a model-training dataset. The `md5(filename) % 10 == 0` 90/10 split is an evaluation partition for reproducible sampling, not ML train/test semantics.

The five live classes match llm-mailroom's `taxonomy.yaml`: `insurance_claim`, `correspondence`, `contract`, `corporate_record`, `merger_agreement`. Retired classes (`compliance_filing`, `court_opinion`, `due_diligence`) stay retired.

## Configs

Load the blind surface and the labels separately, then join on `filename`. The pipeline does not depend on the `datasets` library; it loads through `pipeline/hf_corpus_loader.py` and verifies each row's `content_sha256` against `doc_text`.

| Config         |  Rows | Contents                                                        |
| -------------- | ----: | --------------------------------------------------------------- |
| `default`      | 3,302 | `filename`, `doc_text`, `prompt`, `metadata` — **no labels**    |
| `ground_truth` | 3,302 | Labels (`gt_fields`), hashes, evaluation contract, matter/group |
| `bundles`      |    50 | Synthetic multi-document bundles over real anchors              |
| `streams`      |    62 | Interleaved ingress stream with distractors                     |
| `fixtures`     |    32 | Recovery and adversarial fixtures                               |

```python
from datasets import load_dataset
blind = load_dataset("Lucius-Morningstar/mailroom-dataset", "default", revision="v9.3")
gt = load_dataset("Lucius-Morningstar/mailroom-dataset", "ground_truth", revision="v9.3")
```

## Integrity (EDA P1)

The 2026-09-13 integrity pass reports:

* Blind ↔ ground-truth join is exact: 3,302/3,302 unique filenames, split agreement 2,979/323.
* Split rule `md5(filename utf-8) % 10 == 0 → test` has **zero mismatches** on both configs.
* JSONL parity: `doc_text` byte-equal rate 1.0; expected-label equal rate 1.0.
* CUAD spans: **13,753/13,753 exact offset matches** (100%) on 509 annotated contracts.

Full write-up: [EDA reports](eda-reports.md). Charts: [Visualizations](visualizations.md).

## Rules everyone follows

* **Pin a revision.** Never read the live tip. Code records the revision it used.
* **Keep labels blind.** The model under test only ever sees `default`.
* **One split rule.** Across the family, `md5(filename) % 10 == 0` means test.
* **Subclasses are strata, not classes.** `expected_subclass` is a second-level label. It is not promoted to a top-level class unless the pipeline taxonomy adopts it.
* **Retired classes stay retired.**
