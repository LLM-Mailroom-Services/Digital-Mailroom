# Local Mailroom Sandbox Scripts
- `smoke_campaign.py`: offline pre-flight for an experiment day. Runs mock specialist, `sand42` and pipeline campaigns end to end and fails unless every run completes, the oracle mock's extraction headline is 1.0 and the pipeline classifies every document correctly (stage is reported, not gated). See [`docs/experiments.md`](../docs/experiments.md#pre-flight-smoke-before-an-experiment-day).
