**Pipeline manifests and document catalogs for the Digital-Mailroom monorepo.**

## What This Directory Contains

This directory holds shared manifests that track document processing across the monorepo. Manifests are JSON files that catalog documents, their classification status, and extraction results.

## Manifest Format

Manifests typically contain:
- Document metadata (filename, path, hash)
- Classification results (doc_type, confidence)
- Extraction status and results
- Processing timestamps and audit trail

## Usage

Manifests are generated by the pipeline and consumed by:
- Evaluation scripts
- EDA pipelines
- Report generators
- The-Mailroom visualizer
