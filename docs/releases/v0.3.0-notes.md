## Highlights

This release covers roughly 380 commits since v0.2.0 (2026-09-24). It carries the **SAND-032 → SAND-048 Modal L4 evidence programme** (serving ladder, specialist grid, master score & cost card, the five-cell 1×L4 vs 2×L4 scaling study), the **mailroom watch / job-beacon operator tooling**, and the **SAND-042 schema-adherence root-cause fixes** landed on 2026-10-15.

### Modal L4 evidence programme

- **SAND-032** — Qwen3-8B-AWQ L4 ladder: scale-out, admission ×2 and router-packing fix (`max_inputs = max_num_seqs`), isolated sorter evaluation with accuracy / macro-F1 / confusion reporting, and eval-environment v2 prompt promotion checks.
- **SAND-035 / SAND-036** — cross-repo report audit, Modal + vLLM GPU economics, warm vs cold GPUs, $/1M-token analytics and Modal vs API break-even.
- **SAND-037 / 039 / 040** — aligned 20-cell specialist grid and runbooks, n=50 and n=100 results on one 32K deploy, and the executive master score & cost card with per-cell cards and figures.
- **SAND-042 / 046 – 048** — five-leg 1×L4 / 2×L4 study at C8 / C16 / C32 with parallel-fleet launchers, full telemetry capture (including mid-run KV and queue readings), completeness ledgers and a guarded campaign watcher. The grid completed with all captures.

### Operator tooling

- **mailroom watch** — browser-hosted TUI (`sandbox watch --web`), tray TUI with watchdog, adaptive stall limit and flicker-free repaint, job-aware layouts for Modal runs.
- **Job beacon + persistent board** across the package family.
- **Local-first job traces** — spans mirrored to Parquet, packed, uploaded and pruned (`sandbox traces pack`).
- **Report groups** — nested report tree with validated report-group catalogs and hardened resume preflight.

### SAND-042 schema-adherence RCA (2026-10-15)

- Vendored extraction schemas are now contract-nullable and currency-tolerant. Insurance schema-valid of 0.26–0.34 was traced to a schema bug, not the model.
- Structured-output `intent` hints list the scored vocabulary.
- MAUD scoring reduces chunk-merged answers instead of first-chunk-wins, and compares multi-class answers as sets.
- Vendored `llm-dojo-scoring` refreshed from v0.15 to the schema-adherence-rca line (label intents, MAUD catalog, CMS `claim_type` equivalence).
- Candidate stems `insurance_claims_specialist_simplified_v2` and `merger_agreement_specialist_maud_v2`, plus re-check run configs under `config/runs/rca/`. Re-check runs are spend-gated and have not been executed yet; see `docs/SAND42-SCHEMA-ADHERENCE-RCA.md`.

### Dependencies

- Modal SDK **1.6.1**, plus routine Dependabot updates (python 3.14-slim base image, actions, braintrust, jupyterlab, multidict).

## Compatibility notes

- **Scores from the refreshed scorer are not comparable to SAND-032 … SAND-042 cards** without re-scoring the historical run stores.
- The `sandbox` package version is now **0.3.0**.
