# 🔌 React Desk API

**API client modules for the React operator desk.**

</div>

---

## Purpose

API client modules handle communication between the React desk and the Mailroom backend.

## Endpoints

| Endpoint | Purpose |
|:---|:---|
| `/api/traces` | Pipeline trace data |
| `/api/review-queue` | Human review queue |
| `/api/review/resolve` | Resolve review items |
| `/v1/archive` | Archive operations |
| `/v1/ops` | Operations data |
| `/v1/auth` | Authentication |
