Live pipeline

Each tray is a station. Documents arrive from Langfuse and sit in the tray that matches their current stage. Activate a card to inspect the full trace, or start a replay from History. Replay controls stay pinned above the desk so they remain visible after the view switches to Pipeline.

Queue a document

Set MAILROOM_PIPELINE_URL and MAILROOM_PIPELINE_TOKEN to queue documents into llm-mailroom.

Human review queue

Runs waiting on a person. Correct the doc type or subtype, read the parked file, then Approve (resume extract), Record (audit only), or Requeue (inbox). Requires MAILROOM_PIPELINE_URL and token on the visualizer. Same list as /api/review-queue.

Run history

Replay walks a stored trace through its real span sequence. Playback respects prefers-reduced-motion — it will step without animation when that is set. Controls stay in the replay bar at the top of the page after you leave this desk.

Matters

Langfuse sessions grouped as matters. Open a run to inspect it.

Window metrics

Aggregates from the live source — never estimated locally.

Debug suite

Ring buffer of every fetch, WebSocket frame, view change, and uncaught error. Silent UI failures land here so an agent or a human can pull one bundle instead of guessing from a blank tray.

Browser console: window.__OBSERVATORY_DEBUG__.dump(), .export(), .pullServer(), .pushClient(), .explain(event). Server: GET /api/debug/bundle.
